# 诊断方法论（口径与判定规则）

这套方法不是拍脑袋，全部来自真实账号数据上的实战踩坑。改代码前先读懂这几条，改错口径，结论会整批错。

## 一、数据导入铁律

### 1. 必须吃掉"全部"导出表

小红书后台的「笔记列表明细表」导出，每一份只是**某个时间点的切片**，不是全量。实测案例：只用最近两份合并得 59 条笔记，全部 5 份合并才是 67 条——有 8 条早期笔记**只存在于最早的导出里**。

**漏掉早期高曝光笔记，会把均值抬偏/压低，红黑榜和漏斗结论的倍数直接变错。**

### 2. 去重口径（三类字段三种取法）

同一篇笔记在不同日期导出中重复出现时：

| 字段类型 | 取法 | 原因 |
|---|---|---|
| 计数类（曝光/观看/赞/评/藏/涨粉/转发/时长/弹幕） | `max` | 只增不减 |
| 封面点击率 | **最新快照的值** | 它是**比率**，会随曝光增长而回落；取 max 会留下旧快照的虚高值 |
| 派生指标（互动数/互动率/涨粉效率/综合得分） | 合并后**重算** | 用旧数取 max 会放大误差 |

"哪份最新"靠文件的修改时间（mtime）判定。

### 3. 字段单位

- 封面点击率是**小数**：0.112 = 11.2%。导出表里本来就是小数，不要再除以 100。
- 曝光可以为 0.0：导出时该篇还没跑量，不是脏数据，进"没流量"分桶即可。

## 二、诊断逻辑

### 四段漏斗与漏点判定

```
曝光 → 观看 → 互动 → 涨粉
```

逐段算转化率。判定规则：末端（互动→涨粉）转化率 < 5% 判为**断裂**，最大漏点即在关注引导，而不在封面或内容质量。

实操经验：小账号最常见的病根是"互动→涨粉"断了——几十篇笔记里 90% 涨粉为 0，说明读者看完愿意点赞但没理由关注。这时的杠杆排序是：文末关注钩子 > 主页简介 > 置顶导航，**而不是去优化封面**。

### 黑榜分桶

把表现差的笔记分成三桶，对症下药完全不同：

1. **没流量**（曝光 < 100）：发布/推荐问题。查发布时段（工作日晚 18–22 点、周末午间流量高）、标题前 15 字是否含搜索热词。
2. **有流量没接住**（有曝光但涨粉 0）：缺关注引导。这是最常见的桶。
3. **有效涨粉**：不用管，复制它。

### 埋没检测

曝光 < 100 **且** 互动率进入全账号前 40% 的笔记 = 高质量被埋没。处理方式不是重发，而是用高曝光线做标题钩子交叉引流。

### 内容线策略分工

- 曝光总量最高的线 = **流量引擎**（保曝光，负责吸新）
- 互动率最高的线 = **质量引擎**（做粘性，负责沉淀粉丝）
- 两条线在标题/合集里互相导流；样本 ≤ 2 篇的线先加产观察，不急着下结论。

### 综合得分公式（透明可解释）

```
score = 涨粉 × 5 + 互动数 + 曝光 × 0.01
```

权重含义：涨粉是核心目标所以权重最高；互动衡量内容质量；曝光衡量流量基数。可在 config.json 按自己的目标调整。

## 三、产出纪律

- 每条建议必须带"数据依据"，不能只给结论。
- 预期收益只用保守估算（如当前转化 × 3），并明确标注"估算，非承诺"。
- 价值主张一句话：别人给你看一堆数，这个工具给你的是"**差在哪 + 下一步干嘛**"。
